# SPICESsense

## 🚀 How to Use

1. Download this folder
2. Open the file called `index.html`
3. It will open in your web browser as a website

That’s it.

---

## 📌 What This Is

This is a simple website that shows and explains student engagement data using the SPICES framework.

No installation or coding is needed — it runs entirely in your browser.

---

## 📁 Important Files

* `index.html` → open this file to use the project
* `dev/` → contains the code used to build this (you can ignore this)

---

## ❓ Troubleshooting

* If nothing happens when you click the file, try right-clicking `index.html` and choosing “Open with” → your web browser
* Make sure all files stay in the same folder when downloading
